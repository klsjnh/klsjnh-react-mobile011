## 015.Dependency Rules

| 规则 | 说明 |
|------|------|
| 单向依赖 | `pages → components → features → stores → mock`，禁止反向 |
| 模块自治 | 每个 `features/*` 目录内自带完整的分层（types/api/hooks/components/pages） |
| 类型共享 | 跨模块类型提到 `src/types/`，模块内类型留在 `features/*/types/` |
| 样式隔离 | 全局样式在 `src/styles/`，组件样式避免全局污染 |

## 016.Package Conventions

| 目录 | 约定 |
|------|------|
| `features/*/types/` | 模块内类型，`index.ts` 统一导出 |
| `features/*/api/` | 模块内 API 请求函数 |
| `features/*/hooks/` | 模块内业务 Hooks |
| `features/*/components/` | 模块内组件（不被其他模块复用） |
| `features/*/pages/` | 模块页面组件 |
| `components/` | 跨模块通用组件 |
