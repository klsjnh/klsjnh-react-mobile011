## 013.系统架构（三层架构）

```text
┌─────────────────────────────────────────────────────┐
│                    接入层（UI）                      │
│  src/app/          src/pages/       src/components/  │
│  (App/Router)      (页面组件)       (通用组件)       │
├─────────────────────────────────────────────────────┤
│                    业务层（Logic）                    │
│  src/stores/       src/features/*/hooks/            │
│  (状态管理)        (业务 Hooks)                      │
├─────────────────────────────────────────────────────┤
│                    数据层（Data）                     │
│  src/mock/         src/features/*/api/              │
│  (Mock 数据)       (API 请求)                        │
└─────────────────────────────────────────────────────┘
```

| 模块 | 角色 | 依赖 |
|------|------|------|
| `src/app/` | 应用入口（App / Router / main） | `pages/` / `components/` |
| `src/pages/` | 页面组件（业务页面） | `components/` / `features/` |
| `src/components/` | 通用组件（布局/表单/弹窗） | `stores/` / `types/` |
| `src/features/` | 业务功能模块 | `mock/` / `stores/` |
| `src/stores/` | 状态管理 | `types/` |
| `src/mock/` | Mock 数据 + API | `types/` |
| `src/types/` | 全局类型定义 | — |

**硬约束**

- 依赖方向单向：`pages → components → features → stores → mock`，禁止反向依赖
- 业务模块 = 目录：`features/` 下按业务域分目录，每目录内含 `pages/` / `components/` / `hooks/` / `api/` / `types/`
- 对外契约（路由 `/api/v1/{模块}/{动作}`、响应信封、接口结构）保持稳定，**禁止破坏性变更**
- 交付形态：单文件 `dist/index-inline.html`，零依赖部署

> **目录树、文件清单与逐模块设计** → [013 项目骨架](./013.topic%20-%20structure.md)。

## 015.技术栈基线（简表）

> **权威源**：技术栈以 `docs/015.coding-standards.md` §011 为唯一权威；本表为速览，冲突时以编码标准为准。

| 项 | 选型 |
|----|------|
| 框架 | React **18.3.1**（函数组件 + Hooks） |
| 语言 | TypeScript **5.6.3**（严格模式） |
| 构建 | Vite **6.0.0**（单文件输出） |
| 路由 | Hash Router（内置，`#/` 模式） |
| 状态 | useSyncExternalStore（轻量级全局状态） |
| 样式 | CSS（原生，无 UI 框架） |
| Mock | MSW **2.7.0**（接口 Mock） |
| 包管理 | npm |

## 016.运行视图（构建 · 端口 · 引导链）

- 单页应用（SPA），无服务端，静态文件托管即可
- 开发服务器端口 **5180**，预览服务器端口 **4173**
- 构建链：

| 命令 | 作用 |
|------|------|
| `npm run dev` | 开发服务器（热更新） |
| `npm run build` | 生产构建（单文件输出） |
| `npm run preview` | 预览生产构建 |

- 引导链：

| 步骤 | 动作 |
|------|------|
| 1 | `main.tsx` 渲染 `<App />` |
| 2 | `App` 根据 hash 路由匹配页面 |
| 3 | 页面组件加载 Mock 数据 |
| 4 | 渲染完成 |
