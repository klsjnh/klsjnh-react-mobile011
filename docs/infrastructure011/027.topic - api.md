# 027.topic - api.md — API 接口规范

> **定位**：mobile-admin 的**接口规范** —— 统一信封、拦截器、错误处理、请求封装。

---

## 011.URL 结构

```
/api/v1/{模块}/{动作}
```

| 模块 | 说明 | 示例 |
|------|------|------|
| `auth` | 认证 | `/api/v1/auth/login` |
| `users` | 用户管理 | `/api/v1/users/selectListByPage` |
| `roles` | 角色管理 | `/api/v1/roles/selectList` |
| `permissions` | 权限管理 | `/api/v1/permissions/tree` |
| `menus` | 菜单管理 | `/api/v1/menus/tree` |
| `departments` | 组织管理 | `/api/v1/departments/tree` |
| `audit` | 审计日志 | `/api/v1/audit/loginLogs` |

## 012.统一响应信封

```json
{
  "statusCode": 200,
  "message": "select success",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `statusCode` | int | 业务状态码，与 HTTP 状态码同步 |
| `message` | String | 人读消息 |
| `errorMessage` | String | 仅 debug 态出站 |
| `timestamp` | long | 服务端毫秒时间戳 |
| `traceId` | String | 链路标识 |
| `data` | Object | 业务载荷 |

## 013.标准动作

| 动作 | 方法 | 说明 |
|------|------|------|
| `selectOne` | POST | 查询单个 |
| `selectList` | POST | 查询列表 |
| `selectListByPage` | POST | 分页查询 |
| `insert` | POST | 创建 |
| `update` | POST | 更新 |
| `logicDelete` | POST | 逻辑删除 |
| `export` | POST | 导出 |

## 014.分页形态

```
请求：{"pageIndex": 1, "pageSize": 10, "keyword": "adm"}
响应：{"pageIndex": 1, "pageSize": 10, "total": 181, "totalPages": 19, "rows": []}
```

## 015.错误处理

| statusCode | 场景 |
|:---:|---|
| 200 | 成功 |
| 400 | 入参校验失败 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务端异常 |

## 016.请求封装

```typescript
// 统一请求函数
async function request<T>(url: string, params?: object): Promise<ApiResponse<T>> {
  const response = await fetch(`http://localhost${url}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: params ? JSON.stringify(params) : undefined,
  });
  return response.json();
}
```
