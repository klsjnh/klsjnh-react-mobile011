# 011.agreements.md — 文档体系与编号约定

> **定位**：本仓库文档体系的**编号规则与目录语义** —— 跨语言通用，确保文档编号一致、可追溯。

---

## 011.目录语义

| 目录 | 语义 | 内容 |
|------|------|------|
| `docs/` | 顶层文档 | 四件套（agreements / project-info / coding-standards / api-contract）+ 索引 |
| `docs/infrastructure011/` | 整体底层架构设计 | 横切视角：结构 / 配置 / 持久化 / 数据源 / 存储 / 鉴权 / API |
| `docs/requirement011/` | 业务设计与业务要求 | 需求文档（业务视角） |
| `docs/requirement013/` | 技术方案 | 双源合流（业务要求 → 技术方案） |
| `docs/requirement015/` | 技术实现 | 逐接口规格（JSON 元数据） |
| `docs/sql/` | DDL 唯一真源 | 数据库建表脚本 |

## 012.编号规则

文档编号采用 `三位数字 + 语义` 格式：

| 编号段 | 语义 | 示例 |
|--------|------|------|
| `011` | 约定 / 规则类 | `011.agreements.md` |
| `013` | 项目信息 / 方案类 | `013.project-info.md` |
| `015` | 标准 / 规范类 | `015.coding-standards.md` |
| `016` | 接口通讯类 | `016.api-contract.md` |
| `017` | 开发指南类 | `017.developer-guide.md` |
| `021`-`027` | 基础设施专题 | `021.topic - config.md` |
| `066` | 模板 | `066.template011.md` |

## 013.命名规则

- 文档文件名：`{编号}.{语义}.md` 或 `{编号}.topic - {主题}.md`
- 编号固定三位，不足补零
- 语义段使用小写 + 连接符
- 专题文档使用 `topic -` 前缀

## 014.引用规范

- 文档间引用使用相对路径：`[agreements](./011.agreements.md)`
- 章节引用使用锚点：`[§015](./015.coding-standards.md#015)`
- 跨目录引用：`[infrastructure](../infrastructure011/011.topic - infrastructure.md)`
