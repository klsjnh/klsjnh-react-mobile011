## 011.通用约定

| 项 | 约定 |
|----|------|
| URL 结构 | `/api/v1/{模块}/{动作}`（契约固定，禁止破坏性变更） |
| 大小写 | URL **模块段与动作段**均小驼峰（`userManagement` / `selectListByPage`） |
| HTTP 方法 | 业务接口统一 **POST + JSON body**；**GET 仅用于无参或简单 URL 参数的纯查询** |
| 条件查询 | **带条件的一律 POST + JSON body**（条件放 body） |
| 请求头 | `Content-Type: application/json; charset=UTF-8` |
| 键名 | 请求体与响应体 JSON 键**一律 camelCase** |
| 空值 | 未提供的可选字段可省略；除信封固定字段外不写 `null` 占位 |

## 013.统一响应信封

**所有**端点（成功与失败）共用同一信封；HTTP 状态码与 body `statusCode` **同步**。

> **信封字段固定六项，禁止增删改名**。

### 011.标准形态（写操作成功 · 无数据）

```json
{
  "statusCode": 200,
  "message": "insert success",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": null
}
```

### 013.带数据形态（查询成功）

```json
{
  "statusCode": 200,
  "message": "select success",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": {
    "id": "9f1c4b2a7e0d4c3f",
    "userName": "admin",
    "realName": "管理员",
    "status": "active",
    "createTime": "2026-09-10 17:33:13"
  }
}
```

### 015.失败形态

```json
{
  "statusCode": 401,
  "message": "unauthorized",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": null
}
```

### 016.信封字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `statusCode` | int | 业务状态码，取值见 §019；与 HTTP 状态码同步 |
| `message` | String | 人读消息：成功为 `"<action> success"`；失败为安全提示 |
| `errorMessage` | String | **仅 debug 态出站**的详细信息；其余环境恒为 `""` |
| `timestamp` | long | 服务端毫秒时间戳 |
| `traceId` | String | 链路标识 |
| `data` | Object | 业务载荷；无数据的写操作为 `null` |

## 015.分页形态

### 011.请求形态

```json
{
  "pageIndex": 1,
  "pageSize": 10,
  "keyword": "adm"
}
```

- `pageIndex` / `pageSize` 为**保留字段**；其余条件字段与业务查询字段平铺同级
- 调用方可不传，由服务端归一化（见 §015 · 015）

### 013.响应形态

```json
{
  "statusCode": 200,
  "message": "select success",
  "errorMessage": "",
  "timestamp": 1788645689571,
  "traceId": "b7c1e2f0a3d94e8f",
  "data": {
    "pageIndex": 1,
    "pageSize": 10,
    "total": 181,
    "totalPages": 19,
    "rows": []
  }
}
```

### 015.归一化规则

- `pageIndex >= 1`；`pageSize <= 0` 时回落 **10**
- `total` 为符合条件的总行数；`totalPages = ceil(total / pageSize)`

## 016.查询形态

| 动作 | 方法 | 入参形态 | 出参 `data` 形态 |
|------|------|---------|-----------------|
| `selectOne` | POST（带条件）/ GET（单参数） | 定位键，如 `{"id":"..."}` | **单个对象**或 `null` |
| `selectList` | POST | 条件对象（可空 = 全量） | **对象数组** |
| `selectListByPage` | POST | 分页对象（见 §015 · 011） | **分页对象**（见 §015 · 013） |

- 单条件走**模糊 LIKE**，多条件走**精确 AND**
- 返回的持久化对象必须转 VO 出站（内部字段不得泄漏）

## 017.写操作形态

### 011.新增（`insert` / `create`）

```json
{ "userName": "tom", "realName": "Tom", "role": "user" }
```

响应 `message` 为 `"insert success"`，`data` 返回主键：

```json
{ "id": "9f1c4b2a7e0d4c3f" }
```

### 013.更新（`update` / `save`）

入参为完整对象或增量对象；响应 `message` 为 `"update success"`，`data` 返回**定位键**。

### 015.删除（`logicDelete` / `delete`）

入参为定位键；逻辑删除。响应 `message` 为 `"delete success"`，`data` 返回定位键。

## 019.错误码

| `statusCode` | HTTP | `message` | 场景 |
|:---:|:---:|---|---|
| 200 | 200 | `"<action> success"` / 查询消息 | 成功 |
| 400 | 400 | `bad request` | 入参校验失败 / JSON 解析失败 |
| 401 | 401 | `unauthorized` | 未认证 / 令牌失效 |
| 403 | 403 | `forbidden` | 已认证但无权限 |
| 404 | 404 | `not found` | 资源不存在 |
| 500 | 500 | `internal server error` | 服务端异常（**堆栈不出站**） |
