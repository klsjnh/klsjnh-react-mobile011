## 011.项目背景

企业级移动端管理系统，提供用户、角色、权限、菜单、部门、审计等核心管理功能。采用 React + TypeScript 技术栈，单文件构建交付，支持移动端和桌面端响应式。

## 012.项目目标

- 提供完整的企业管理后台移动端解决方案
- 统一的接口通讯规范
- 可扩展的模块化架构
- 单文件构建，零依赖部署

## 013.技术栈

| 类别 | 技术 | 版本 |

| 语言 | TypeScript | 5.6.3 |

## 014.模块与依赖

```text
src/
├── app/                  # 应用入口（App / Router / main）
├── components/           # 通用组件（Layout / PageHeader / SearchBar）
├── features/             # 业务功能模块
│   ├── auth/             # 认证模块
│   ├── user-management/  # 用户管理
│   ├── role-management/  # 角色管理
│   ├── menu-management/  # 菜单管理
│   ├── role-group/       # 角色组管理
│   ├── permission/       # 权限管理
│   └── system-settings/  # 系统设置
├── stores/               # 状态管理
├── mock/                 # Mock 数据
├── styles/               # 全局样式
└── types/                # 全局类型
```
