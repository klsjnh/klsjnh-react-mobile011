# 015.coding-standards.md — 编码标准（TypeScript + React 18）

> **定位**：mobile-admin 项目的**编码标准** —— 技术栈 / 组织方式 / 命名 / 风格 / 注释。

---

## 011.技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React 18 | 函数组件 + Hooks |
| 语言 | TypeScript | 严格模式 |
| 构建 | Vite 6 | 单文件输出 |
| 路由 | Hash Router | 内置 hash 路由 |
| 状态 | useSyncExternalStore | 轻量级全局状态 |
| 样式 | CSS | 原生 CSS，无 UI 框架 |
| Mock | MSW | 接口 Mock |

## 012.分层

| 层 | 职责 | 目录 |
|----|------|------|
| 接入层 | 页面组件、路由适配 | `src/pages/` / `src/app/` |
| 业务层 | 业务逻辑、状态管理 | `src/stores/` / `src/features/*/hooks/` |
| 数据层 | Mock API、数据模型 | `src/mock/` / `src/features/*/api/` |

## 013.铁律

- **函数组件**：一律使用函数组件 + Hooks，禁止 class 组件
- **TypeScript**：严格模式，禁止 `any`，类型定义完整
- **命名**：组件 PascalCase，方法/变量 camelCase，常量 UPPER_SNAKE_CASE
- **文件**：一个组件一个文件，文件名与组件名一致
- **注释**：公共函数/组件必须有 JSDoc 注释
- **错误处理**：业务异常统一处理，禁止吞掉错误

## 014.命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 组件 | PascalCase | `UserListPage` |
| 文件 | PascalCase.tsx | `UserListPage.tsx` |
| 方法 | camelCase | `getUserList` |
| 变量 | camelCase | `userInfo` |
| 常量 | UPPER_SNAKE_CASE | `MAX_PAGE_SIZE` |
| 类型 | PascalCase | `UserInfo` |
| 接口 | PascalCase | `ApiResponse` |
| 路由 | kebab-case | `/user-management` |
| URL 动作 | camelCase | `selectListByPage` |
| JSON 键 | camelCase | `statusCode` |
